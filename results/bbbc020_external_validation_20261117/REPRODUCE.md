# BBBC020 direct replacement validation
Use Python 3.12 with NumPy 2.3.5, SciPy 1.17.0, pandas 2.2.3, Pillow 13, matplotlib. Prepare a separate R environment using conda-forge and bioconda with R 4.5.3, EBImage 4.52.0, RobustGaSP 0.6.8, magick 2.9.1, pracma 2.4.4. Extract the archive into a dedicated folder. All shell commands below are relative to that folder. To protect the distributed results when rerunning, work on a copy and move the included results directory aside first.

Source images and per-cell segmentations from Roland Lang, BBBC020 v1, Broad Bioimage Benchmark Collection, Ljosa et al., Nature Methods 2012. Source images/reference masks are available under CC BY-NC-SA 3.0 at https://bbbc.broadinstitute.org/BBBC020 . Credit Roland Lang and BBBC for the source data. Included derived predicted masks are supplied with attribution for noncommercial use under the same terms. Source images and human TIFFs are retrieved from Broad by the commands below. The native RGB C1 file has identical R/G components and an empty B component. Use native R component. Each field is divided according to the R tile-size rule. Both arms optimise the same global first-tile parameters from two starts, then refit mean/variance per tile. No ground-truth input to the reconstruction, thresholds, or watershed.

The archive contains frozen protocol, source hashes, cohort manifest, calibration of numerical integration, per-field outcomes and final compressed masks for all arms, and a reference R session. Full precision, large intermediate reconstructions can be regenerated by fitting. To rescore the supplied masks, run data preparation and score.py with the pinned repository available. The win/tie/loss columns in summary.csv are the signs of the numeric differences for all metrics, including merge/split counts, where fewer is usually preferable. The bootstrap columns give descriptive, field-resampled percentile intervals, conditional on this study. Partial annotation can penalize genuine predictions. The public corpus does not supply an exhaustive ignore mask in the published cell archive. Whole-field FP and AP are scored against the available annotated objects. Sample recall refers to the annotated objects.
