Fast-QEP 冻结权重后的独立采样验证
2026-10-15

结论

两组验证均已完成，耗时 370.20 秒，约 6.2 分钟。
采样收敛、数值检查和预先规定的精度改进判据全部通过。
修正后的控制变量确实改善了梯度估计精度，但仍未检出可分辨的 QEP
参数调整方向。按执行前冻结的停点，不自动扩大这项局部梯度训练方案。

关键结果

数据集       收敛检查   精度改进验证   最大 |QEP梯度−GP梯度|/MCSE   合格调整方向
nuclei         通过         通过                    0.647                    无
whole-cell     通过         通过                    0.712                    无

预设方向门槛同时要求：差异超过 3 MCSE、缩放后幅度超过 1e-8，且四条新链
的平均梯度差异方向一致。此次十个坐标都没有超过 3 MCSE，且每个坐标的
四条链都出现了不同符号。该判据是数值可分辨性的描述性筛查，不是 p 值，
也不是多重检验校正后的显著性结论。

精度修正是否真的有效？

是，在新的随机种子下通过了冻结判据。相对于原先 b=1 的固定校正：
nuclei 行/列核参数梯度 MCSE 分别下降 41.78% / 45.09%；
whole-cell 行/列核参数梯度 MCSE 分别下降 89.90% / 90.43%。

这些降幅针对原固定校正。与完全不用控制变量的原始估计相比，
whole-cell 行/列核梯度 MCSE 比例为 0.879 / 1.006，主要是在消除原校正
引入的额外噪声。不能将相对低效估计器的大幅改进解释成 QEP 分割优势。

技术检查

每个目标使用四条链，每链 2000 次预热、4000 个保留样本，每十个样本
计算一次梯度。nuclei 新 fixture=8202，whole-cell=8212，base seed=20261015；
它们与用于确定权重的原 8102/8112 链不同。
所有权重由旧样本确定，执行期间未重新估计或选择。
两个目标的加权梯度最大 R-hat 分别约 1.00208 / 1.00020；
bulk ESS 最低约 1282 / 1469；tail ESS 最低约 1373 / 1489。
保留样本期间 HMC 发散、非有限提案和全局步数值失败均为零。
冻结源码、参数、权重、原 R 重建锚点和输出校验均通过。

如何理解这个结果

已支持的事实：先前固定控制项造成的精度损失可以修正，且修正在新采样中复现。
尚未支持的主张：在这两个 GP 拟合参数点附近，q=1.5 提供足够可分辨的
局部超参数学习方向，从而值得直接启动完整 QEP 训练。

当前实践决定：停止自动加长采样、重试种子或放宽门槛；不直接启动完整
QEP 参数优化。以后若继续这个分支，需要新的理论或模型结构依据。
这不是证明梯度严格为零、全局没有其他最优解，或所有 Fast-QEP 模型都不可能有效。
逐坐标筛查也未穷尽全部联合参数方向。

适用范围

仅使用 nuclei 和 whole-cell 各一个开发图像的第一块；模型、q=1.5、GP
拟合参数、图像和采样器均保持冻结。随机数是新的，显微图像不是新的。
因此，这次是独立的蒙特卡洛验证，不是独立图像上的泛化验证。
没有执行任何 QEP 参数更新、全图重建、RobustGaSP 阈值选择、EBImage
watershed 或 cleanup，也没有新的 AP 结果。
程序保存的 nuisance ECM suggestion 没有被应用。
此前固定参数 Fast-QEP 与 Fast-GP 的端到端 AP 持平结果保持原有解释。
